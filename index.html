①Definition Recap

Throughout we use 0-based indexing: cards are numbered 0, 1, …, n−1 from the top down. For the packet (0, 1, …, k−1 | k, …, n−1), after COATing k cards:

(0, 1, …, k−1 | k, …, n−1) ⟶ (k, …, n−1 | k−1, k−2, …, 0)

This is a permutation σ in the symmetric group Sn :σ(j) = j−k (j ≥ k); σ(j) = n−1−j (j < k). Its order is the number of times COAT must be repeated before the packet returns to its original state for the first time; numerically it equals the least common multiple of the cycle lengths. We use 0-based indexing because the residue range {0,…,k−1} of the congruence B(x) ≡ n−1−x (mod k) for the bounce map below is exactly the set of the top k legal positions — with 1-based indexing that congruence can leave residue 0, which then has to be read specially as position k.

hyperCOAT(k > n): when k cards are to be counted out but the packet holds only n, we deal cyclically — "finish the packet, pick up the dealt cards and keep counting" — until k cards have been counted, then place those k cards as a block beneath the remainder. Below we verify that this always folds back into a single ordinary operation.

④What This Figure Is Saying

  1. The overCOAT plateau (k ≥ n/2 and k < n): the order is always 4. "Plateau" is only a metaphor for the heatmap: this large flat region of one uniform colour (order = 4) is exactly the visible shape of the Four OverCOATs Principle, just like a plateau on a relief map. Example: n = 13, k = 8 (the classic case from the book), σ = (0 12 4 8) (1 11 3 9) (2 10) (5 7) (6), and lcm(4, 4) = 4.
  2. The full-reversal band (k = n−1 and k = n): counting out n−1 cards reverses them onto the bottom, giving exactly (n−1, n−2, …, 0) — the very samepermutation as counting out all n cards (a full reversal: an involution of order 2, undone by doing it twice). So the narrow gold band on the heatmap is reallytwo columns wide.
  3. k = 1: equivalent to the n-cycle "move the top card to the bottom", with order exactly n — the only source of odd orders in the whole tablethe only (and then only when n is odd).
  4. The surprise at k = 2 (with a rigorous proof): when n is even the order is n; when n is odd (n = 2m+1) the order is (n²−1)/4 = m(m+1). Below 20the largest order among ordinary COATs, 90, occurs at n = 19, k = 2:(0 18 16 14 12 10 8 6 4 2) (1 17 15 13 11 9 7 5 3), lcm(9,10)=90.
    proof(0-based indexing): COAT(n,2) acts as σ(0) = n−1, σ(1) = n−2, σ(j) = j−2 (j ≥ 2): from any position each step moves up by 2, and on landing at 0 or 1 it bounces back to the bottom. (i) n = 2m even: the chain 0 → n−1 → n−3 → ⋯ → 1 is joined via σ(1) = n−2 to the chain n−2 → n−4 → ⋯ → 2, which closes via σ(2) = 0, so all n cards formthe sameone cycle of length n, hence order = n. (ii) n = 2m+1 odd: the even-indexed cards form the cycle (0, n−1, n−3, ⋯, 2) of length m+1, and the odd-indexed cards form the cycle (1, n−2, n−4, ⋯, 3) of length m. The two are disjoint and m, m+1 are coprime, so the order is lcm(m, m+1) = m(m+1) = (n²−1)/4. ∎ (This parity contrast mirrors exactly the fate of "transposition pairs" in the evenness theorem below: for n even {0, 1} is a transposition pair, while for n odd both positions are fixed points — the latter being the only case with k ≥ 2 that has no transposition pair at all.)
  5. The underCOAT region (2 ≤ k < n/2): the order is always even (with a rigorous proof). Apart from k = 1, the underCOAT region contains no odd orders at all.
    proof(0-based indexing, positions 0 … n−1 from the top down): positions evolve as follows — at position j ≥ k each step moves up by k (j ↦ j−k); as soon as a card enters the top k cards (position x ∈ {0,…,k−1}) its next step jumps to the bottom, n−1−x; it then keeps moving up by k until it re-enters the top, landing at position B(x), where B(x) ≡ n−1−x (mod k) — the residue range {0,…,k−1} is exactly the set of the top k legal positions, which is precisely why this page uses 0-based indexing (with 1-based indexing the residue of B(x) ≡ n+1−x can be 0, which must then be read specially as position k). Since B(B(x)) ≡ x (mod k), we know B is an involution on {0,…,k−1}, and distinct bounce segments never share a position (two segments sharing a position would force x ≡ y (mod k) with x, y ∈ {0,…,k−1}). So every cycle corresponds to exactly one B-orbit: a two-element orbit {x, y} (x ≠ y) yields a cycle of length 2 + 2(n−1−x−y)/k — necessarily even; a fixed point (2x ≡ n−1 (mod k)) yields a cycle of length 1 + (n−1−2x)/k.When do transposition pairs exist?(this is exactly the boundary between k = 2 and k ≥ 3) (i) k ≥ 3: if B fixed every point, then 2x ≡ n−1 (mod k) would hold for all x ∈ {0,…,k−1}. Takingadjacenttwo neighbouring positions x and x+1 (both exist since k ≥ 2) and subtracting the two congruences gives 2 ≡ 0 (mod k), i.e. k divides 2 — contradicting k ≥ 3. Hence for k ≥ 3 a transposition pairnecessarily exists, so there is necessarily a cycle of even length and the order is even. (ii) k = 2: the same subtraction only gives 2 ≡ 0 (mod 2) —holds identically, so there is no contradiction; all-fixed is logically possible here, and indeed it happens: for n odd, B(0) ≡ n−1 ≡ 0 and B(1) ≡ n−2 ≡ 1 (mod 2), so both positions are fixed points and no transposition pair exists. This is the only case with k ≥ 2the only case with no transposition pair(namely k = 2 with n odd; for n even, B(0) = 1 and B(1) = 0, so {0, 1} is a transposition pair and the cycle length n is even). For this single exception we fall back on counting: the two cycle lengths (n+1)/2 and (n−1)/2 areconsecutive integers, so one of them is even and the lcm is even as well. ∎
  6. The ultimate structure (rigorously derivable): B is a reflection on the ring Zk — the transposition pattern, the order and even the cycle expression can be completely reconstructed. Arrange the top k positions as a ring mod k; then B(x) ≡ n−1−x (mod k) is exactlya reflection (the mirror axis is fixed by c = (n−1) mod k). So the pattern of "transposed elements" is purely geometric symmetry:a transposition = a symmetric pair {x, y} on the ring (x + y ≡ n−1 (mod k)); a fixed point = a point lying on the axis itself (2x ≡ n−1 (mod k)). Their numbers are fixed entirely by parity:

    Rebuilding recipe (cycle expression and order for underCOAT): ① every B-orbit {x, y} (a transposition) gives the cycle (x, n−1−x, n−1−x−k, n−1−x−2k, …, y, n−1−y, n−1−y−k, …, x) — from x it bounces to the bottom n−1−x, moves up by k each step and lands exactly at y on re-entering the top; then it bounces from y and climbs back to x the same way. Length = 2 + 2(n−1−x−y)/k; ② every fixed point x gives the cycle (x, n−1−x, n−1−x−k, …, x), length = 1 + (n−1−2x)/k; ③ order(n, k) = lcm of all orbit lengths.corollary: the sums of transposition pairs satisfy x+y ≡ n−1 (mod k) with 1 ≤ x+y ≤ 2k−3, so they take at most the two values {c, c+k}, and therefore transposition cyclesat most two distinct lengths; there are at most two fixed points and their lengths areadjacent — hence order(n, k) is alwaysthe lcm of at most 4 numbers. In particular, when n ≡ 1 (mod k) we have c = 0 and B degenerates to the cleanest inversion j ↦ −j (mod k), with 0 as its fixed point (plus k/2 when k is even) — exactly the situation in the example n = 17, k = 4 below. Verified case by case for n ≤ 60, k < n/2: the cycles rebuilt from the formula and those obtained by direct simulation areidentical, element for element.∎
    Corollary (the ratio structure: the exact bound for "transposition length ≈ 2 × fixed-point length"): write q = ⌊(n−1)/k⌋ and c = (n−1) mod k, and classify by "layer" t ∈ {0, 1}: fixed points satisfy 2x = c + tk and transpositions satisfy x + y = c + tk. A stronger corollary: all cycle lengths lie in {q, q+1, 2q, 2q+2}, and since lcm(2q, 2q+2) = 2q(q+1) (q and q+1 are coprime), order(n, k) always divides 2q(q+1). Example: n = 21, k = 6 (q = 3, c = 2, all four slots filled) has cycle lengths 4, 3, 8, 6 and order = 24 = 2q(q+1), attaining the upper bound; n = 17, k = 4 (c = 0) has transposition length 8 = 2q, exactly twice the t = 1 fixed-point length 4, and differing from twice the other fixed-point length 5 by exactly 2. Verified on all 2450 underCOAT combinations with n ≤ 100. ∎
  7. hyperCOAT (k > n, the hatched region): the folding law for cyclic dealing. Write k = q·n + r (q = ⌊k/n⌋, 0 ≤ r < n). Implemented by cyclic dealing — "finish the packet, pick up the dealt cards and keep counting" — the whole operation folds exactly into:q even ⟶ equivalent to COAT(n, r) (for r = 0 this is the identity: nothing happens);q odd ⟶ equivalent to flipping the top n−r cards in place (for r = 0 it is a full reversal). Intuition: each time a whole packet of n cards is dealt through, the packet is reversed exactly once; this happens q times, and the remaining r cards are then finished off as an ordinary COAT. So the order of a hyperCOAT has only two possible fates — it falls back to the order of COAT(n, r), or is at most 2 (flipping a top block is an involution), which is why the values in the hatched region are generally so small. Verified by simulation on all 1200 combinations with n ≤ 20, k ≤ 60: zero mismatches.
  8. A group-theoretic view: COAT(n, k) is a fixed permutation σ in Sn (the longest reflection w₀ when k = n), with order = the lcm of the cycle lengths; hyperCOAT is folded back into these two kinds of operation by the law above. The entire orbit structure of repeated COATing is hidden in this table.
